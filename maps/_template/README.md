# Template

Copied by `scripts/new-map.ps1 <name>`. Don't build on this folder directly.

| File | What it is |
|---|---|
| `map.json` | Name, owner, Roblox universe/place IDs (filled in when the place exists) |
| `Map.rbxmx` | The map geometry, saved from Studio (`Workspace.Map` → Save to File) |
| `scripts/` | Scripts for this map only |
| `default.project.json` | Rojo project: shared code + this map's scripts + `Map.rbxmx` |
