# /new-map — the map studio pipeline

Arguments: `$ARGUMENTS` → first word = map folder (kebab-case), the rest = the idea.
If either is missing, ask once, then go.

You are the **orchestrator**. You don't design or build — you brief agents, enforce the order and
the gates, and keep the human informed in one short line per step.

## Model fallback (Fable → Opus)
`idea-generator`, `level-designer` and `checker` run on **Fable 5.2**. If one of those agent calls
fails because the model is unavailable (usage credits off, limit reached, "model not available"),
call the **same agent again with the same prompt and `model: "opus"`**, and tell the user once:
"Fable unavailable — using Opus 5.5 for <agent>". Never fall back for other errors.

## 0. Branch
```
git switch main && git pull
powershell -ExecutionPolicy Bypass -File scripts/new-map.ps1 <map>
```
(creates `maps/<map>/` from the template on branch `map/<map>`). Delete the template's `Map.rbxmx`
— this map will be generated by code.

## 1. Idea → `idea-generator`
Prompt: map folder, the idea, "write maps/<map>/DESIGN.md".
**GATE 1 — human:** show the pitch, stages table and [new] mechanics. Ask: approve / change / redo.
Loop until approved. Commit: `<map>: design`.

## 2. Layout → `level-designer`
Prompt: "DESIGN.md is approved; write maps/<map>/LAYOUT.md".
Show the hardest jump and the part budget in one line. Commit: `<map>: layout`.

## 3. Build → in parallel, ONE message, two Agent calls
- `map-builder`: "build maps/<map> from LAYOUT.md"
- `gameplay-scripter`: "implement the [new] mechanics of maps/<map>" — skip if DESIGN has none.

They own disjoint files (CLAUDE.md → File ownership), so they can share the branch.
Then `polish`: "polish maps/<map>". Commit: `<map>: build`.

## 4. Check → `checker`
Prompt: "check maps/<map> on branch map/<map>".
- **PASS** → step 5.
- **FAIL** → send each FIX line to the agent named in brackets (independent owners in parallel),
  commit `<map>: fixes from review`, run `checker` again. **Max 3 rounds**; then stop and give the human
  the remaining FIX list.

## 5. Pull request
```
lune run scripts/build-maps <map>        # make sure Map.rbxmx is current
bash scripts/check.sh                    # must say All checks passed.
git push -u origin map/<map>
gh pr create --fill --title "<map>: new map" --body-file -   # body = PR template filled in + checker's PR SUMMARY
```
Set `"status": "testing"` in map.json before the push.

## 6. Hand-off (to the human, ≤ 6 lines)
PR link · pitch · stages · checker verdict · "Your friend must approve the PR; download the place
from the PR's CI run → Artifacts → places to playtest. Publish later with Actions → Publish map."

## Never
- push to `main`, merge the PR, or publish to Roblox — humans do those.
- edit `Map.rbxmx` by hand, or let two agents edit the same file at once.
- skip GATE 1.
